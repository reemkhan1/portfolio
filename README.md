# Reem Khan — Portfolio

Personal portfolio for Reem Khan, a product-minded builder and inventor working across product strategy, human behavior, spatial experience, and emerging technology.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000`.

## Structure

- `index.html` — portfolio markup, styling, and interactions
- Root-level image and font files — assets used by the portfolio
